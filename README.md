# Yandex Disk Rescue

Создавайте локальные копии нужных файлов с Яндекс Диска. Вы сами выбираете, что сохранить и куда. Приложение работает в режиме чтения и не изменяет файлы в облаке.

## Возможности

- Просматривать файлы и папки, переходить во вложенные каталоги и видеть размер, дату изменения и статус каждого элемента.
- Выбирать отдельные файлы и папки для резервного копирования на выбранный диск или в папку.
- Следить за очередью и прогрессом: видеть, какой файл загружается, и останавливать копирование при необходимости.
- Настраивать пропуск ранее загруженных файлов, автоматические повторы, интервал повтора и тайм-аут загрузки.
- Если сетевой сбой мешает скачать оригинал изображения, приложение автоматически запрашивает уменьшенное превью и сохраняет его отдельным файлом. Превью помогает получить изображение, когда оригинал временно недоступен, и не заменяет оригинал.
- Подключать несколько аккаунтов Яндекс Диска и переключаться между ними.
- Хранить пароли приложений WebDAV в защищённом хранилище операционной системы.

## Скачать и установить

Откройте [страницу последнего релиза](https://github.com/stug111/yandex-disk-rescue-releases/releases/latest) и в разделе **Assets** выберите пакет для своей системы:

- **macOS Apple Silicon** — файл `.dmg` с пометкой `aarch64`;
- **Windows x64** — установщик `.exe` или `.msi`;
- **Linux x64** — пакет `.deb` или приложение `.AppImage`.

На macOS откройте `.dmg` и перетащите Yandex Disk Rescue в папку **Программы**. В Windows запустите установщик. В Linux установите `.deb` или запустите `.AppImage`.

### Первый запуск на macOS

Если macOS блокирует запуск, после первой попытки открыть приложение перейдите в **Системные настройки → Конфиденциальность и безопасность** и подтвердите открытие. Подробности — в [инструкции Apple](https://support.apple.com/en-us/102445). Скачивайте приложение со [страницы релизов](https://github.com/stug111/yandex-disk-rescue-releases/releases/latest).

## Подключить аккаунт Яндекс Диска

Для подключения нужен тариф Яндекс 360 с доступом по WebDAV и пароль приложения типа **Файлы WebDAV**. Обычный пароль Яндекс ID не подойдёт. [Инструкция Яндекса по WebDAV](https://yandex.ru/support/yandex-360/customers/disk/web/ru/webdav?lang=ru)

1. Создайте пароль типа **Файлы WebDAV** в настройках [паролей приложений Яндекс ID](https://yandex.ru/support/id/ru/authorization/app-passwords.html). Скопируйте его — Яндекс покажет пароль только один раз.
2. В приложении нажмите **Подключить аккаунт**.
3. В разделе **Добавить WebDAV** укажите название аккаунта, логин Яндекс ID и созданный пароль приложения.
4. Нажмите **Добавить**. Чтобы переключиться между аккаунтами, нажмите на название аккаунта в правом верхнем углу.

Новый пароль приложения может начать действовать через 2–3 часа.
