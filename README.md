# Yandex Disk Rescue

Приложение для создания резервных копий файлов с Яндекс Диска.

## Возможности

- Просматривать файлы и папки на Яндекс Диске, открывать вложенные папки и видеть размер, дату изменения и статус файлов.
- Выбирать конкретные файлы и папки для сохранения локальной копии на выбранный диск или в папку.
- Следить за очередью и ходом копирования: видеть прогресс и текущий файл, при необходимости останавливать загрузку.
- Настраивать пропуск ранее скачанных файлов, автоматические повторы, интервал повтора и тайм-аут загрузки.
- Если оригинал изображения не удаётся скачать из-за сетевой ошибки, приложение пытается запросить уменьшенное превью и сохранить его отдельно. Превью не заменяет оригинал; поддержка запроса превью текущим Яндекс WebDAV не проверена на реальном аккаунте.
- Подключать несколько аккаунтов Яндекс Диска и переключаться между ними.
- Не менять облачные файлы: приложение только просматривает их и скачивает выбранные копии.
- Хранить пароли приложений WebDAV в защищённом хранилище операционной системы.

## Скачать и установить

Пакет текущего релиза предназначен для Mac с Apple Silicon (M1 и новее).

1. Откройте [страницу последнего релиза](https://github.com/stug111/yandex-disk-rescue-releases/releases/latest).
2. В разделе **Assets** скачайте установщик `.dmg` с пометкой `aarch64`.
3. Откройте скачанный файл и перетащите Yandex Disk Rescue в папку **Программы**.
4. Запустите приложение.

### Первый запуск на macOS

Если macOS блокирует приложение, сначала убедитесь, что скачали его со [страницы релизов](https://github.com/stug111/yandex-disk-rescue-releases/releases/latest). Если для запуска нужно снять блокировку, откройте Terminal, вставьте команду и нажмите Enter:

```sh
xattr -dr com.apple.quarantine "/Applications/Yandex Disk Rescue.app"
```

Команда удаляет атрибут карантина у приложения и обходит часть первоначальных проверок Gatekeeper. Выполняйте её только для приложения, скачанного со страницы релизов. [Подробнее о безопасном открытии приложений на Mac](https://support.apple.com/en-us/102445).

## Подключить аккаунт Яндекс Диска

Для подключения нужны доступ WebDAV в тарифе Яндекс 360 и пароль приложения типа **Файлы WebDAV**. Обычный пароль Яндекс ID не подойдёт. [Инструкция Яндекса по WebDAV](https://yandex.ru/support/yandex-360/customers/disk/web/ru/webdav?lang=ru)

1. Создайте пароль типа **Файлы WebDAV** в настройках [паролей приложений Яндекс ID](https://yandex.ru/support/id/ru/authorization/app-passwords.html). Скопируйте его — Яндекс покажет пароль только один раз.
2. В приложении нажмите **Подключить аккаунт**.
3. В разделе **Добавить WebDAV** укажите имя аккаунта, логин Яндекс ID и созданный пароль приложения.
4. Нажмите **Добавить**. Для переключения между аккаунтами нажмите на имя аккаунта в правом верхнем углу.

Новый пароль приложения может начать действовать через 2–3 часа.
